# TripMate Kenya

TripMate Kenya is a travel-planning platform designed to make domestic travel in Kenya easier, more affordable, and more social for young travelers.

The repository contains the source code for building the 12-slide draft presentation using Python's `python-pptx` library.

## Key Features Covered in the Deck

* **The Problem & Solution:** Addresses fragmented trip planning and manual bill splitting for Gen Z domestic travelers.
* **Market Opportunity:** Highlights Kenya's tourism potential, including KES 452B in tourism earnings and domestic tourism activity.
* **Monetization:** Booking commissions, SME subscriptions, brand partnerships, and TripMate Plus.
* **Growth Strategy:** Micro-influencer campaigns and campus ambassador networks across Kenyan universities.

## 🛠️ How to Run Locally

### Prerequisites

Make sure Python is installed on your computer.

### Installation & Execution

1. Clone the repository:

```bash
git clone https://github.com/quintermoraa63-netizen/tripmate-kenya.git
cd tripmate-kenya
```

2. Install the required dependency:

```bash
pip install python-pptx
```

3. Run the Python presentation script:

```bash
python your_script_name.py
```

Replace `your_script_name.py` with the actual name of your Python file.
